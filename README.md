# 🎾 Tennis AI Coach

MediaPipe와 OpenCV를 활용한 테니스 자세 분석 AI 웹앱입니다.
자신의 스윙 영상을 업로드하고, 선택적으로 롤모델 선수와 비교해 전문적인 코칭을 받아보세요.

---

## 설치 방법

### 요구사항
- macOS (Apple Silicon 및 Intel 모두 지원)
- Python 3.9 이상 (3.11 권장)
- pip

### 1. 가상환경 생성 및 활성화

```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. 의존성 설치

```bash
pip install -r requirements.txt
```

> Apple Silicon(M1/M2/M3)에서 `mediapipe` 설치에 오류가 생기면 아래 명령을 먼저 실행하세요.
>
> ```bash
> pip install --upgrade pip setuptools wheel
> ```

---

## 실행 방법

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 자동으로 열립니다.

## 사용 방법

### 1단계 — 설정 (사이드바)
| 항목 | 옵션 |
|------|------|
| 분석 모드 | 단독 분석 / 롤모델 비교 분석 |
| 스트로크 | 포핸드 / 백핸드 |
| 주 사용 손 | 오른손잡이 / 왼손잡이 |
| 촬영 방향 | 측면 (권장) / 정면·후면 |

### 2단계 — 영상 업로드 탭
1. **나의 스윙 영상** 을 업로드합니다.
2. 비교 분석 모드라면 **롤모델 영상** 도 업로드합니다.
   - YouTube URL 입력은 향후 버전에서 지원 예정입니다.
3. **"영상 처리 시작"** 버튼을 누릅니다.

### 3단계 — 프레임 선택 탭
각 동작 단계(레디 포지션 → 테이크백 → 임팩트 → 팔로스루)에서  
슬라이더로 가장 대표적인 순간의 프레임을 선택합니다.  
스켈레톤 오버레이와 신뢰도 지표를 참고해 선택하세요.  
선택이 완료되면 **"분석 시작"** 버튼을 누릅니다.

### 4단계 — 분석 결과 탭
- **전체 유사도 점수** (비교 모드 전용)
- **단계별 유사도 차트**
- **스켈레톤 오버레이 나란히 비교**
- **주요 개선점 코칭 문장** (한국어)
- **추천 연습 드릴**
- 관절별 각도 수치 메트릭 카드

### 5단계 — 보고서 다운로드 탭
- **CSV**: Excel·스프레드시트에서 열 수 있는 데이터 표
- **Markdown**: Notion·Obsidian에서 열 수 있는 구조화 문서

## 분석 항목

| 항목 | 설명 |
|------|------|
| 팔꿈치 각도 | 손목-팔꿈치-어깨 사이 각도 |
| 어깨 각도 | 팔꿈치-어깨-골반 사이 각도 |
| 무릎 각도 | 골반-무릎-발목 사이 각도 |
| 상체 기울기 | 어깨-골반 연결선과 수직선 사이 각도 |
| 손목 높이 | 골반 기준 손목의 정규화 높이 |
| 손목-몸통 거리 | 어깨 너비로 정규화한 손목-몸통 중심 거리 |
| 어깨 회전량 | 어깨 연결선과 수평선 사이 각도 |
| 골반 회전량 | 골반 연결선과 수평선 사이 각도 |
| 팔로스루 방향 | 손목-팔꿈치 벡터 방향 각도 |

> 키·체형·카메라 거리 차이를 줄이기 위해 모든 좌표는  
> **골반 중심** 을 원점으로 이동하고 **어깨-골반 거리** 로 정규화합니다.

## 출력 예시

```
전체 유사도: 72 / 100

주요 개선점:
1. 테이크백에서 어깨 회전이 부족합니다. 어깨를 충분히 돌려서 파워를 축적해보세요.
2. 임팩트 순간 팔꿈치가 몸에 너무 가깝게 굽혀져 있습니다. 팔을 뻗어서 공을 맞히세요.
3. 팔로스루가 짧게 끝납니다. 손목을 반대쪽 어깨까지 끌어올려보세요.

추천 연습:
1. 어깨 회전 섀도우 스윙을 20회 반복해보세요.
2. 임팩트 지점을 몸 앞쪽에 두는 드릴을 해보세요.
3. 팔로스루를 반대쪽 어깨까지 완성하는 연습을 해보세요.
```

## 한계점

- 측면 촬영에 최적화되어 있으며, 정면/후면 촬영은 정확도가 낮습니다.
- 두 영상의 촬영 각도가 다를 경우 비교 정확도가 낮아집니다.
- 영상의 조명 조건과 배경이 포즈 추출 정확도에 영향을 줍니다.
- 현재는 사람 관절 분석에 집중하며 **라켓·공 추적은 지원하지 않습니다**.
- YouTube URL을 통한 롤모델 영상 불러오기는 현재 지원하지 않습니다.
- 2D 영상 기반이므로 깊이 방향(z축) 각도는 부정확할 수 있습니다.
